# 👁 Глазок — телефон-камера

Открытая трансляция с камеры одного телефона на любое другое устройство.
Телефон-камера сам запускает трансляцию и всё время видит, что она идёт;
зритель подключается по ссылке и смотрит видео + звук в реальном времени.

Зависимостей нет — нужен только Node.js (v18+).

## Запуск на компьютере

```bash
node server.js          # порт 8000
# или на другом порту:
PORT=8080 node server.js
```

Проверка на самом компьютере: http://localhost:8000
(на localhost камера заработает и без HTTPS)

## Как открыть на телефонах

Браузеры разрешают доступ к камере только по **HTTPS**, поэтому телефонам
нужен https-адрес. Проще всего поднять туннель (у тебя уже стоит ngrok):

```bash
ngrok http 8000
```

Ngrok покажет адрес вида `https://xxxx.ngrok-free.app` —
открой его на обоих телефонах (подойдёт любая сеть, не только Wi-Fi).
Видео при этом идёт напрямую между устройствами, сервер передаёт
только служебные данные.

Альтернатива без регистрации — cloudflared (один exe, без аккаунта):

```bash
cloudflared tunnel --url http://localhost:8000
```

## Пользование

1. Телефон А: открыть `https://адрес/` → «Этот телефон — камера» →
   разрешить камеру и микрофон. Поставить на зарядку.
2. Телефон Б (или любой браузер): тот же адрес → «Смотреть трансляцию» →
   кнопка «▶ Смотреть».
3. На камере: кнопка «Сменить камеру» переключает фронтальную/заднюю.
   На зрителе: звук и полный экран.

## Работа через интернет (телефоны в разных местах)

Это основной режим: ngrok-ссылка глобальная, телефоны могут быть
в разных городах и сетях — важно лишь, что оба вышли в интернет.
Видео идёт напрямую между телефонами (или через TURN-релей, если
операторский NAT мешает), сервер передаёт только лёгкий служебный
трафик.

Два способа поднять сервер:

**Способ А — свой компьютер + ngrok.** Компьютер должен быть включён,
пока нужна связь. У бесплатного ngrok адрес меняется при каждом
запуске; в бесплатном аккаунте можно забронировать один постоянный
домен (Dashboard → Domains), тогда команда выглядит так:

```bash
ngrok http --url=ваш-домен.ngrok-free.app 8000
```

**Способ Б — бесплатное облако (компьютер не нужен).** Например, render.com:

1. Загрузить папку phonecam в репозиторий на GitHub.
2. render.com → New → Web Service → выбрать репозиторий.
3. Build command: пусто (зависимостей нет), Run command: `npm start`.
4. Через пару минут получишь постоянный адрес вида
   `https://glazok-xxxx.onrender.com` — открой его на телефонах.

Сервер держит только сигналинг, нагрузки почти нет — бесплатного
тарифа хватает. Если сервис «уснёт» от неактивности, первое открытие
ссылки занимает секунд 30–50, потом всё как обычно.

## Честные ограничения

- **Экран телефона-камеры должен быть включён.** Приложения в браузере
  приостанавливаются при блокировке экрана. Страница держит экран активным
  (wake lock), но выключить экран совсем — значит остановить трансляцию.
  Полностью выключенный телефон транслировать не может ничто.
- Задержка примерно 0.3–1.5 секунды, качество зависит от сети.
- Для «сложных» операторских NAT уже встроен TURN-релей (Open Relay Project),
  так что соединяться можно и из мобильного интернета. Если всё равно не
  соединяется — попробуй переключиться Wi-Fi ↔ мобильный интернет.
